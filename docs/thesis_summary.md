# 논문 요약

## 1. 연구 배경

반도체 제조 공정은 초미세 공정과 고집적화 기술의 발전으로 인해 점점 더 복잡해지고 있다. 현대 반도체 생산 라인에서는 온도, 압력, 유량, 전류 등 다양한 공정 변수가 대규모 센서 네트워크를 통해 수집된다. 이러한 공정 데이터는 생산 수율 향상, 품질 안정화, 불량 조기 탐지에 중요한 역할을 한다.

그러나 실제 반도체 공정 데이터는 고차원성, 결측치, 클래스 불균형 문제를 동시에 포함하고 있다. 특히 대표적인 공개 산업 데이터셋인 SECOM 데이터셋은 수백 개 이상의 센서 변수와 다수의 결측값을 포함하고 있으며, 불량 샘플 비율이 전체의 약 6% 수준에 불과하다. 이러한 특성은 일반적인 머신러닝 모델의 학습을 어렵게 만들고, 모델이 다수 클래스인 정상 샘플에 편향된 예측을 수행하게 하여 실제 불량 샘플 탐지 성능을 저하시킬 수 있다.

본 연구는 이러한 문제를 해결하기 위해 결측치 대치, 클래스 불균형 처리, 특성 선택, 분류 모델을 조합한 다양한 머신러닝 파이프라인을 설계하고, 각 구성 요소가 반도체 불량 검출 성능에 미치는 영향을 체계적으로 분석하였다. 특히 결측값을 단순히 제거하거나 복원해야 하는 대상으로만 보지 않고, 결측 발생 여부 자체가 공정 이상과 관련된 보조 정보를 포함할 수 있는지 함께 검토하였다.

## 2. 문제 정의

본 연구에서 다룬 핵심 문제는 결측치와 클래스 불균형이 동시에 존재하는 반도체 제조 공정 데이터에서 불량 샘플을 효과적으로 탐지하는 것이다.

기존 연구들은 주로 결측값을 제거하거나 대치하여 완전한 입력 행렬을 구성하는 데 초점을 두었다. 그러나 실제 산업 데이터에서 결측은 단순한 무작위 오류가 아니라 설비 이상, 통신 불량, 측정 실패, 공정 불안정 등과 관련되어 발생할 가능성이 있다. 따라서 결측 발생 여부 자체가 공정 이상 또는 불량 발생과 관련된 정보를 포함할 수 있다고 보았다.

이에 본 연구에서는 결측 발생 패턴을 결측지시변수, 즉 Missing Indicator 또는 M feature로 표현하였다. M feature는 특정 센서 변수의 값이 결측이면 1, 관측값이 존재하면 0으로 표시하는 이진 변수이다. 본 연구는 이러한 M feature를 기존 공정 변수와 결합하거나, M feature만 독립적으로 사용했을 때 불량 검출 성능에 어떤 영향을 미치는지 분석하였다.

## 3. 데이터셋

본 연구에서는 UCI Machine Learning Repository에서 제공하는 SECOM 데이터셋을 사용하였다. SECOM 데이터셋은 반도체 제조 공정에서 수집된 센서 기반 공정 데이터로, 다수의 센서 변수, 광범위한 결측치, 심각한 클래스 불균형 문제를 동시에 포함하고 있다. 이러한 특성 때문에 SECOM 데이터셋은 결측 및 불균형 환경에서의 반도체 공정 이상 탐지 연구에 자주 사용되는 벤치마크 데이터셋이다.

본 연구에서는 먼저 원본 데이터에서 결측률이 50% 이상인 변수를 제거하였다. 이후 분산이 0.05 이하인 변수도 제거하였다. 이 과정을 거친 데이터를 본 연구의 기준 데이터인 Raw 데이터로 정의하였다.

## 4. 방법론

본 연구의 전체 머신러닝 파이프라인은 데이터 정제, 결측치 대치 및 입력 구성, 클래스 불균형 처리, 특성 선택, 분류 모델 학습 및 평가의 단계로 구성하였다.

결측치 대치 방법으로는 Raw, Mean Imputation, Inpainting KNN, MICE, MissForest를 사용하였다. 또한 각 대치 방법에 결측지시변수인 M feature를 추가한 조건을 함께 구성하였다. 원래 공정 변수는 사용하지 않고 결측 여부 정보만 사용하는 M_only 조건도 별도로 포함하였다. 이에 따라 결측치 대치 및 입력 구성 단계에서는 총 11가지 조건을 비교하였다.

클래스 불균형 처리를 위해서는 SMOTE 적용 조건과 미적용 조건을 비교하였다. SMOTE는 소수 클래스 샘플을 합성하여 훈련 데이터의 클래스 분포를 보정하는 오버샘플링 기법이다. 본 연구에서는 데이터 누출을 방지하기 위해 SMOTE를 각 교차검증 루프의 훈련 데이터에만 적용하고, 검증 데이터에는 적용하지 않았다.

특성 선택 기법으로는 chi-square, f_classif, mutual information, FPR, FDR, FWE를 사용하였다. chi-square, f_classif, mutual information은 단변량 점수를 기준으로 상위 50개 특성을 선택하도록 설정하였다. FPR, FDR, FWE는 p-value 기반 선택 절차에서 유의수준 0.05를 기준으로 적용하였다. 특성 선택을 수행하지 않는 Raw 조건도 함께 포함하여 총 7가지 특성 선택 조건을 비교하였다.

분류 모델로는 KNN, SVM, Logistic Regression, Random Forest, XGBoost, HGB를 사용하였다. KNN은 거리 기반 모델, Logistic Regression은 선형 분류 모델, SVM은 커널 기반 모델이며, Random Forest, XGBoost, HGB는 트리 기반 앙상블 또는 부스팅 계열 모델이다. 이를 통해 서로 다른 학습 구조를 가진 모델들이 결측치 및 클래스 불균형 환경에서 어떤 성능 차이를 보이는지 비교하였다.

전체 실험에서는 11개 입력 조건, 2개 클래스 불균형 처리 조건, 7개 특성 선택 조건, 6개 분류 모델을 조합하여 총 924개의 후보 파이프라인 조합을 설계하였다. 이 중 유효하게 평가된 조합을 대상으로 성능을 비교·분석하였다. 모든 평가는 9-Fold 교차검증 구조에서 수행하였으며, 외부 검증 fold의 정보가 모델 선택 과정에 직접 유입되지 않도록 하였다.

또한 일부 모델 하이퍼파라미터와 분류 임계값은 외부 검증 fold를 직접 사용하지 않고, 훈련 데이터 내부의 holdout 검증 절차를 통해 F2-score 기준으로 선택하였다.

## 5. 평가지표

본 연구에서는 반도체 불량 검출 문제의 특성을 고려하여 Recall, F2-score, TNR을 주요 평가 지표로 사용하였다.

Recall은 실제 불량 샘플 중 모델이 불량으로 올바르게 탐지한 비율을 의미한다. 반도체 제조 공정에서는 불량 샘플을 정상으로 잘못 판단하는 Type II Error의 비용이 크기 때문에 Recall을 중요한 지표로 보았다.

F2-score는 Precision보다 Recall에 더 큰 가중치를 부여하는 지표이다. 따라서 불량 샘플 탐지가 중요한 본 연구의 목적에 적합한 평가 지표로 사용하였다. F2-score를 통해 불량 탐지 성능을 중심으로 하되, Precision의 영향도 일정 부분 함께 고려하였다.

TNR은 실제 정상 샘플 중 모델이 정상으로 올바르게 분류한 비율을 의미한다. Recall만 높이는 모델은 정상 샘플까지 과도하게 불량으로 판단할 수 있으므로, 현장 적용 가능성을 고려하기 위해 TNR을 함께 평가하였다.

## 6. 실험 결과 분석

유효 평가된 전체 파이프라인 조합을 기준으로 성능을 비교한 결과, 파이프라인 구성 요소와 모델 조합에 따라 불량 검출 성능이 크게 달라졌다. 전체 유효 조합의 평균 성능 분포를 살펴보면, SMOTE 적용 여부, 특성 선택 방법, 대치 방식, 분류 모델의 조합에 따라 Recall, F2-score, TNR 사이의 균형이 서로 다르게 나타났다.

평균 F2-score 기준 상위 조합에는 InpaintingKNN_M / Raw / Raw / Random Forest, InpaintingKNN / SMOTE / Raw / XGBoost, InpaintingKNN_M / Raw / mutual_info / Random Forest 등이 포함되었다. 이들 조합은 불량 탐지 성능과 정상 샘플 구분 성능 사이에서 비교적 양호한 균형을 보였다. 다만 특정 기준값으로 조합을 선별하기보다, 전체 유효 조합의 성능 분포와 구성 요소별 경향을 함께 해석하였다.

클래스 불균형 처리 측면에서 SMOTE는 일부 조합에서 Recall을 높이는 데 기여할 수 있었으나, 평균 F2-score와 TNR 측면에서는 조합에 따라 효과가 달라졌다. 따라서 SMOTE는 모든 조건에서 일관된 성능 향상을 제공하는 방법이라기보다, 대치 방식, 특성 선택, 분류 모델과 함께 고려해야 하는 구성 요소로 해석하였다.

특성 선택 방법별 비교에서는 특성 선택을 수행하지 않은 Raw 조건과 f_classif, FPR, mutual_info 기반 선택 방식이 서로 다른 장단점을 보였다. 일부 조합에서는 모든 변수를 유지하는 방식이 정보 손실을 줄이는 데 유리했으며, 다른 조합에서는 변수 수를 줄이는 방식이 모델 안정성에 도움을 줄 수 있었다.

모델별 비교에서는 Random Forest, XGBoost, KNN 등이 일부 조합에서 상대적으로 높은 F2-score를 보였다. 그러나 모델 성능은 단일 모델의 우열만으로 결정되기보다, 결측치 처리 방식, M feature 결합 여부, 클래스 불균형 처리, 특성 선택 방식과의 상호작용에 따라 달라졌다.

## 7. 결측 지시변수 효과 확인

본 연구의 핵심 분석 중 하나는 결측지시변수, 즉 M feature의 효과를 검토하는 것이었다. 이를 위해 동일한 균형화 조건, 특성 선택 방법, 분류 모델을 공유하면서 M feature 적용 여부만 다른 조합들을 1:1로 대응시켜 성능 차이를 비교하였다.

분석 결과 M feature는 모든 조합에서 일관된 성능 향상을 제공하지는 않았다. 그러나 일부 파이프라인에서는 F2-score, Recall, TNR을 동시에 개선하는 효과가 관찰되었다. 예를 들어 InpaintingKNN / Raw / mutual_info / Random Forest 조합과 InpaintingKNN_M / Raw / mutual_info / Random Forest 조합의 비교에서, M feature를 추가한 이후 F2-score는 0.3182에서 0.3766으로 상승하였고, Recall은 0.5616에서 0.6374로, TNR은 0.7051에서 0.7316으로 함께 향상되었다.

전체 1:1 대응 비교 결과, M feature 추가 이후 F2-score가 상승한 조합은 147개로 확인되었다. 이 중 F2-score가 상승하면서 Recall이 하락하지 않고 TNR도 함께 증가한 조합은 40개였다. 이러한 결과는 M feature가 모든 조건에서 보편적으로 우수한 기법은 아니지만, 특정 파이프라인 환경에서는 기존 공정 변수와 결합될 때 성능을 보완하는 보조 신호로 작동할 수 있음을 보여준다.

M_only 조건은 결측 여부 정보만을 사용하여 결측 패턴 자체의 예측 가능성을 확인하기 위한 보조 실험으로 활용하였다. M_only 결과는 결측 여부 정보만으로도 일부 조건에서 불량 탐지에 관한 신호가 존재할 수 있음을 시사하지만, 기존 공정 변수를 대체하는 독립적인 핵심 입력으로 사용하기에는 한계가 있었다. 따라서 M feature는 단독 입력보다는 기존 공정 변수와 결합되었을 때 불량 검출 성능을 보완하는 보조 신호로 활용될 가능성이 더 크다고 해석하였다.

## 8. 최종 추천 파이프라인 제시

본 연구에서는 전체 유효 조합 중 평균 F2-score가 높은 조합을 중심으로 최종 추천 파이프라인을 검토하였다. 앞선 구성 요소별 평균 비교와 달리, 최종 추천 조합은 개별 파이프라인 단위의 절대 성능과 Recall, TNR의 균형을 함께 고려하여 선정하였다.

첫 번째 조합은 InpaintingKNN_M / Raw / Raw / Random Forest였다. 해당 조합은 평균 F2-score 0.3891로 가장 높은 성능을 기록하였으며, Recall 0.6263, TNR 0.7604를 보였다. 이는 불량 검출 성능과 정상 샘플 구분 성능 사이에서 비교적 균형 잡힌 결과로 해석된다.

두 번째 조합은 InpaintingKNN / SMOTE / Raw / XGBoost였다. 해당 조합은 F2-score 0.3800, Recall 0.6939, TNR 0.6938을 기록하였다. 세 추천 조합 중 가장 높은 Recall을 보였다는 점에서, 불량 샘플 탐지를 상대적으로 중시하는 상황에서 유용한 후보 조합으로 해석된다.

세 번째 조합은 InpaintingKNN_M / Raw / mutual_info / Random Forest였다. 해당 조합은 F2-score 0.3766, Recall 0.6374, TNR 0.7316을 기록하였다. 이 조합은 M feature 추가 효과가 비교적 뚜렷하게 관찰된 대표 사례로, 동일 조건의 M feature 미적용 조합과 비교했을 때 F2-score, Recall, TNR이 모두 향상되었다.

종합적으로 최종 추천 조합에서는 Inpainting KNN 기반 대치와 Random Forest 또는 XGBoost 계열 분류 모델이 상위권에 포함되었다. 또한 상위 조합 중 일부가 M feature를 포함하고 있어, 결측지시변수가 모든 조건에서 일관된 성능 향상을 제공하지는 않더라도 특정 파이프라인 환경에서는 불량 검출 성능을 보완하는 데 기여할 수 있음을 확인하였다.

## 9. 결론

본 연구는 결측치와 클래스 불균형이 동시에 존재하는 반도체 공정 데이터 환경에서 머신러닝 기반 불량 검출 성능을 분석하기 위해 다양한 파이프라인 조합을 비교·평가하였다. 이를 위해 결측치 대치 방법, 클래스 불균형 처리 적용 여부, 특성 선택 기법, 분류 모델을 조합한 총 924개의 후보 파이프라인을 설계하였으며, SECOM 데이터셋을 기반으로 유효한 실험 결과를 분석하였다.

실험 결과, 파이프라인 구성 요소에 따라 불량 검출 성능 차이가 크게 나타났다. InpaintingKNN_M, InpaintingKNN, MICE 등 대치 조건과 Random Forest, XGBoost, KNN 등 분류 모델은 일부 조합에서 경쟁력 있는 성능을 보였다. 그러나 성능은 단일 구성 요소에 의해 결정되기보다 입력 구성, 불균형 처리, 특성 선택, 분류 모델의 조합에 따라 달라졌다.

클래스 불균형 처리 측면에서 SMOTE는 일부 조합에서 Recall 개선에 기여할 수 있었으나, 평균 F2-score와 TNR 측면에서는 조건에 따라 효과가 제한적으로 나타났다. 이는 SMOTE가 소수 클래스 탐지 민감도를 높이는 데 기여할 수 있지만, 정상 샘플 구분 성능과의 균형 측면에서는 전처리 및 모델 조합에 따라 신중하게 적용되어야 함을 보여준다.

또한 결측 여부 자체를 나타내는 M feature를 도입하여 결측 패턴의 정보적 활용 가능성을 분석하였다. M feature는 모든 조합에서 일관된 성능 향상을 제공하지는 않았으나, 일부 조합에서는 F2-score, Recall, TNR을 동시에 개선하는 효과가 관찰되었다. 특히 InpaintingKNN_M / Raw / mutual_info / Random Forest 조합은 동일 조건의 M feature 미적용 조합보다 세 지표가 모두 향상되어, 특정 파이프라인 환경에서 결측 발생 여부가 보조 정보로 작동할 가능성을 보여주었다.

결론적으로 본 연구는 반도체 공정의 결측 및 불균형 환경에서 머신러닝 파이프라인 구성 요소들의 성능 특성을 비교·분석하고, 결측 패턴이 특정 조건에서 불량 검출을 보조하는 정보로 활용될 가능성을 확인하였다는 점에서 의의를 가진다. 향후 연구에서는 실제 공정 환경에 보다 근접한 데이터셋을 활용한 외부 검증과 함께, 결측치를 별도로 대치하지 않고 결측 구조 자체를 모델이 직접 학습하는 no-imputation 기반 접근으로 확장할 수 있다.
